# Security Policy

## Supported version

Security fixes are prepared against the latest published TimeDeck release.

## Reporting a vulnerability

Please do not publish credentials, personal data or an exploitable vulnerability in a public issue. Use GitHub's **Report a vulnerability** feature in the repository's Security tab when it is enabled. Include the affected version, reproduction steps and potential impact.

TimeDeck is a local-first static web application. It does not require an account or cloud backend. Do not include private browser exports or personal configuration files in bug reports.
